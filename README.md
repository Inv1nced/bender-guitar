# Bender — урок для электрогитары

Интерактивный урок по [каверу Dave Shinoda](https://www.youtube.com/watch?v=4pqW8o3jWDQ) на песню The Paradox feat. Travis Barker. Семь частей, табы с подсветкой, аппликатуры, синтетическая гитара, эталон открытых струн и метроном. Тренажёр работает прямо в браузере.

Учебный ритм следует общей сетке кавера. В бридже часть длительностей восстановлена приблизительно. Два перехода, для которых в описании нет отдельных табов, отмечены ссылками на видео.

## Запуск

Открой [урок на GitHub Pages](https://inv1nced.github.io/bender-guitar/) или запусти в каталоге проекта `python3 -m http.server 8000` и зайди на [localhost:8000](http://localhost:8000). Сборка и установка зависимостей не требуются.

`song.mjs` содержит структуру урока, аппликатуры и учебные ритмы. `audio.mjs` генерирует звук струн средствами Web Audio. Запись кавера на сайт не загружается.
